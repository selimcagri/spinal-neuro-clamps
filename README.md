# Spinal Neuropixels Clamp & Spinal Window Tools (3D Models)

Open-source **spinal Neuropixels probe clamp** and **spinal window accessories** for chronic/acute neurophysiology.

## Contents
- `neuropixels/` – clamp, adapters, cable relief
- `spinal window/` – frames, holders, positioning jigs

## Build
**Prototype (SLA):** Formlabs **Form 3**, **Black v4** resin, **50 µm** layers.  
**Hardware:** M2/M3 screws, brass heat-set inserts.  
**In-vivo (Metal):** DMLS/SLM in **316L** or **Ti-6Al-4V**; stainless fasteners.

## Quick Assembly
1) Print (50 µm), deburr.  
2) Install heat-set inserts.  
3) Mount to micromanipulator/stereotaxic.  
4) Seat probe, set depth, lock.

## Status / Durum 
Prototypes fabricated; cadaver validation done. Next: production in implant-compatible metals (Ti-6Al-4V / 316L).

## Safety
Research use only — **not a medical device**. Follow your institution’s sterilization/biocompatibility protocols and approvals.
